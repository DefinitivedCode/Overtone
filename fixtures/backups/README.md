# Frozen backup fixtures

`v{n}.json` are backups exactly as produced by schema version *n*. They are **frozen**: never
regenerate or edit them. `src/db/backup/backup.test.ts` imports every file here into the current
version. When the backup schema changes, add a new `v{n+1}.json` generated by the new exporter and
keep the old files so migrations stay tested.

`v1.json` contains two original (non-copyrighted) songs: a Korean one with a repeated chorus, one
learned line and one correction, and a Japanese one.
